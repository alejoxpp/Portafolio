# Imágenes del portafolio

Coloca aquí tus imágenes para reemplazar los placeholders. Si falta alguna,
el sitio usa automáticamente una imagen de respaldo (onerror).

Archivos esperados:
- `profile.jpg`        -> Foto de perfil (sección "Sobre mí")
- `vlover.jpg`         -> Portada del proyecto Vlover
- `transferplayer.jpg` -> Portada del proyecto TransferPlayer
- `senda-explorer.jpg` -> Portada del proyecto Senda Explorer

Formatos sugeridos: JPG/PNG, ~1350px de ancho para las portadas.
